从今天起，你在 chat 中使用的记忆与 Claude Cowork 中的记忆是同一份。现在，无论你在哪里与 Claude 协作，它都从已经了解的你出发。你可以逐个主题查看 Claude 记住的全部内容，并编辑或删除其中任何一项。对于被视为敏感的主题——比如健康状况或信仰——Claude 默认不会存入记忆；但如果这些恰好是你厌倦了反复解释的话题，你可以在「记忆」设置中打开它们。

![Claude 记忆功能在 chat 与 Cowork 间共享的示意图](../assets/memory-everywhere-hero.png)

## **Claude Cowork 与 chat 共用同一份记忆**

Cowork 现在有了记忆，而且与你在 chat 中使用的是同一份，这意味着更少的重复解释，更多的接续上次进度。当 Cowork 在云端执行任务时，Claude 从你的 chat 对话中记住的内容都在那里，反之亦然。你在数月对话中积累的上下文——例如你的 Q3 优先事项和各个项目的状态——在你把任务交给 Cowork 的那一刻就已就位，而 Cowork 中出现的新情况也会带回 chat。

让 Cowork 起草一份给经理的进展汇报，它已经知道对方是谁、以及她喜欢怎样的汇报写法。在 chat 里为你正在筹办的会议头脑风暴议程；当 Cowork 制作预算与后勤文档时，它知道参会人数、城市和演讲者。在 chat 里解释一次你的团队如何定义各项指标，此后 Cowork 制作的每一份季度业务回顾演示文稿都会沿用它们，无需重新交底。

## **记忆随对话即时更新**

Claude 现在会在你对话的过程中就把主题加入记忆，而不是等对话结束后再做总结。提一句你的项目截止日期挪到了九月，下一次对话就已经知道了，你不必特意说「记住这件事」。你可以随时暂停记忆或将其重置。

## **查看并编辑已保存的记忆**

Claude 记住的所有内容，都以文件列表的形式呈现在「记忆」设置的 Topics 之下，你可以在那里阅读、编辑或删除每一条。这些文件都很短，而且一处修正处处受益：在一个文件里改正公司的旧名称，从此每一次对话都会用对。

## **决定是否让 Claude 记住敏感主题**

默认情况下，Claude 不会存储与个人或敏感事项相关的主题，例如你的健康状况、种族、民族、宗教信仰、政治立场、性别认同，以及其他类似领域。

但一些人认为敏感的内容，另一些人可能觉得让 Claude 记住会很有用。如果你选择打开「在记忆中包含敏感主题」，Claude 就会在为你每周备餐推荐食谱时，记住你对麸质过敏这件事。

在该设置打开的状态下，每当 Claude 把属于这类主题的内容存入记忆时，你都会看到一条提示。Claude 只保存此后出现的敏感主题——在你打开该设置之前的内容不会被追溯保存。你可以随时关闭这项设置。

为保护你的安全与隐私，即便你打开了敏感主题记忆，仍有一些主题 Claude 不会存储。这包括敏感的身份识别号码（社会安全号码、政府颁发的身份证件号码等）、犯罪记录、移民状态，以及任何违反我们《可接受使用政策》（AUP）的内容。当 Claude 无法把这类信息更新进记忆时，它会告知你。访问[帮助中心](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context#h_6fe1d0e66f)了解更多。

## **开始使用**

在 Free、Pro 和 Max 方案上，记忆功能在网页版、桌面端和移动端均默认开启。请注意，将敏感主题存入记忆默认是关闭的。在 iOS 和 Android 上，请将移动应用更新到最新版本以获取最近的更新。对于 Team 和 Enterprise，由管理员控制其组织内的可用性，且在个人用户主动开启前记忆处于关闭状态。

访问 [Settings > Memory](https://claude.ai/new#settings/customize-memory) 开启记忆功能，并管理 Claude 记住的内容。
