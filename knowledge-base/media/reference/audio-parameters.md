# 音频参数：采样率、位深、声道数

## 1. 采样率（Sample Rate）

采样率指每秒对模拟声音采样的次数，单位 kHz。采样率决定能记录的最高频率。

- 根据奈奎斯特定理，可记录的**最高频率 = 采样率的一半**。人耳听觉上限约 20 kHz，因此采样率至少要 40 kHz 才能完整覆盖
- 常见值：

| 采样率 | 最高可记录频率 | 典型场景 |
|---|---|---|
| 44.1 kHz | ~22 kHz | CD 音频、绝大多数音乐 |
| 48 kHz | ~24 kHz | 视频/影视音频、广播电视 |
| 96 kHz | ~48 kHz | 高解析录音、专业制作 |
| 192 kHz | ~96 kHz | 顶级高解析、专业母带 |

- 视频制作中 **48 kHz 是事实标准**（视频文件音轨几乎都是 48 kHz）；44.1 kHz 是音乐行业标准

## 2. 位深（Bit Depth）

位深指每个采样值用多少比特表示，决定**动态范围**（能记录的最轻到最响的声音跨度）。

| 位深 | 动态范围 | 典型场景 |
|---|---|---|
| 16-bit | ~96 dB | CD、消费级成品 |
| 24-bit | ~144 dB | 录音、混音、专业制作 |
| 32-bit float | 极大 | 录音采集（防削波）、后期处理 |

- 24-bit 主要是**制作**规格（留后期处理余量），16-bit 是**成品**规格（CD）；48 kHz/16-bit 与 48 kHz/24-bit 都是视频音轨常见组合
- 位深不足的表现：低电平处出现可闻量化噪声；位深足够则听感无差异，追求更高位深是留处理余量而非"更响更清晰"

## 3. 声道数（Channels）

声道数决定声音的空间结构，布局表见 `audio-codecs.md`（单声道 / 立体声 / 5.1 / 7.1 / 对象音频）。关键点：声道数决定"要编码几路声音"，直接影响码率与体积。

## 4. 音频码率计算

未压缩（PCM）音频码率是确定的：

```
音频码率 = 采样率 × 位深 × 声道数
```

例：48 kHz × 16-bit × 2（立体声）= 1536 kbps ≈ 1.5 Mbps——这就是 WAV/CD 级音频体积的来源。

- 有损编码（AAC / MP3 / Opus）远低于该值：立体声 128–192 kbps 已够高质量
- 无损压缩（FLAC / ALAC）介于两者之间，典型约为原始 PCM 的一半

## 5. 常见误区

- **"采样率越高音质越好"**：对同一素材，高于播放能力的采样率无听感增益；提升采样率的实际价值是给处理（变速/移调）留余量
- **"24-bit 一定比 16-bit 好听"**：成品回放环节人耳几乎无法分辨；24-bit 的价值在制作过程
- **"单声道音质差"**：单声道≠低质量，语音/电话本来就是单声道；声道数决定空间感，不决定音质高低
