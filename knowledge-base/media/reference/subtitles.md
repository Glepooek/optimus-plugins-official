# 视频字幕：形态与格式对比

## 1. 三种形态

| 形态 | 说明 | 特点 |
|---|---|---|
| 硬字幕（烧录） | 字幕合成进画面，是视频的一部分 | 任何播放器都显示；不可关闭/切换，转码后不可逆 |
| 内封软字幕 | 字幕作为**字幕流**存在容器里（如 MKV / MP4） | 可开关/切换语言；播放器需支持该字幕编码与容器 |
| 外挂字幕 | 独立字幕文件与视频同目录（同名加载） | 最灵活，可替换/编辑；需播放器自动匹配加载 |

## 2. 文本字幕格式

文本字幕是"文本 + 时间轴"，体积小、可编辑、可搜索：

| 格式 | 扩展名 | 样式/特效 | 说明 |
|---|---|---|---|
| SubRip | `.srt` | 无（纯文本） | 最通用，几乎所有播放器/平台支持 |
| Advanced SubStation Alpha | `.ass` / `.ssa` | 丰富（字体、位置、动画、卡拉OK） | 动画/特效字幕事实标准 |
| WebVTT | `.vtt` | 基础样式 | 网页（HTML5 `<video>`）标准 |
| SubViewer / MicroDVD | `.sub` | 无 | 老式文本字幕，兼容性差 |

- `.ass` 的样式依赖本机字体，缺失字体时字幕会退化显示
- 文本字幕文件本身有**编码**问题：中文旧字幕常见 GBK 编码，读取工具需按正确编码打开（现代标准为 UTF-8）

## 3. 图形字幕格式

图形字幕是**位图**（预先渲染好的画面），体积大、不可编辑、不可搜索，但显示效果与源一致：

| 格式 | 扩展名 | 来源 |
|---|---|---|
| PGS（HDMV PGS） | `.sup` / 内嵌 | 蓝光碟片字幕 |
| VobSub | `.sub` + `.idx` | DVD 字幕 |
| DVB 字幕 | 内嵌 | 数字电视广播 |

- 图形字幕依赖**分辨率**：位图按设计分辨率渲染，放大/缩小播放可能模糊
- 图形字幕 → 文本字幕没有自动可靠方案（OCR 质量参差）；文本 → 图形可行（渲染成图）

## 4. 常见误区

- **"MKV 的字幕导不出来"**：内封软字幕可以提取，用 ffmpeg / ffprobe 定位字幕流后流复制导出（见 `media-stream-basics.md`）
- **"字幕总是要烧录"**：只有硬字幕才烧录；软字幕与图形字幕在支持对应格式的播放器里直接显示
- **"SRT 能显示彩色样式"**：SRT 纯文本无样式；需要样式/特效选 ASS
