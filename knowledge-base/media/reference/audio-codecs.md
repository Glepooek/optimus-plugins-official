# 音频编解码器：有损 / 无损与环绕声格式对比

## 1. 音频编码分类

音频编解码器按是否保留原始数据分为三类：

| 类型 | 代表 | 说明 |
|---|---|---|
| 未压缩 | PCM | 采样值原样存储，体积最大，无损 |
| 无损压缩 | FLAC、ALAC | 压缩后仍能还原原始采样，体积约减半，无损 |
| 有损压缩 | MP3、AAC、Opus、Vorbis | 丢弃人耳不敏感信息换体积大幅下降，有损 |

## 2. 常见音频编解码器对比

| 编解码器 | 类型 | 质量/效率 | 典型用途 |
|---|---|---|---|
| PCM | 未压缩 | 无损，体积大 | 录音、WAV/AIFF、CD 抓轨 |
| FLAC | 无损压缩 | 无损，体积约为 PCM 一半 | 无损音乐存档、高品质播放 |
| ALAC | 无损压缩 | 无损 | Apple 生态无损 |
| MP3 | 有损 | 基准效率 | 通用音乐、老设备、播客 |
| AAC | 有损 | 同码率优于 MP3 | 广播、Apple 音乐、现代设备 |
| Opus | 有损 | 效率极高、低延迟 | 语音（VoIP）、低码率高质网络流 |
| Vorbis | 有损 | 接近 AAC | 开源生态（Ogg 容器）、游戏 |
| AC-3 | 有损 | 环绕声（5.1） | Dolby Digital：DVD、电视广播 |
| E-AC-3 | 有损 | 环绕声（5.1/7.1） | Dolby Digital Plus：蓝光、流媒体 |
| DTS / DTS-HD | 有损/无损 | 环绕声 | 蓝光电影音轨 |
| WMA | 有损/无损 | — | Windows 老生态 |

## 3. 声道布局

声道数决定声音的空间结构，常见布局：

| 布局 | 含义 | 典型来源 |
|---|---|---|
| 单声道 Mono | 单声道 | 电话、语音、老录音 |
| 立体声 Stereo | 左右两声道（2.0） | 音乐、多数日常音频 |
| 5.1 | 前左右 + 中置 + 后左右 + 低音炮 | 电影、电视广播、DVD |
| 7.1 | 5.1 加左右后环绕 | 蓝光、高端影院 |
| 对象音频（Dolby Atmos 等） | 声道 + 空间对象元数据 | 现代影院、流媒体、游戏 |

## 4. 怎么选

- **语音 / 播客 / 低码率**：**Opus**（效率最高）或 **AAC**
- **通用音乐**：**AAC**（现代设备）或 **MP3**（兼容最广）
- **无损存档 / 高品质**：**FLAC**（通用）或 **ALAC**（Apple 生态）
- **电影环绕声**：保留原轨（AC-3 / E-AC-3 / DTS）不动，用流复制即可；转成立体声会丢弃环绕信息（见 `media-stream-basics.md` 的流复制）
- **录音 / 剪辑中间文件**：**PCM**（WAV / AIFF）

## 5. 常见误区

- **"码率越高音质一定越好"**：对同一编码器成立，跨编码器比较无意义——192 kbps 的 AAC 音质通常优于 256 kbps 的 MP3
- **"转成无损就无损了"**：有损源转无损不恢复信息，见 `video-quality.md` 的有损/无损讨论
- **"杜比 = 5.1 环绕"**：Dolby 是一族技术（AC-3 / E-AC-3 / TrueHD / Atmos），不只指声道数；是否环绕由声道布局决定
