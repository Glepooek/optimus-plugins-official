# 04 · 版本与发布

> 更新历史：2026-08-23 创建，迁移自 `csharp/16-collaboration.md` §5 并新增 Tag 命名细节。

## 1. 版本与发布

- **必须**：发布走 tag + 语义化版本（[SemVer](https://semver.org/lang/zh-CN/)）
- **必须**：版本号由语义决定——破坏性变更升 major
- **应该**：发布说明随版本 tag 附带
- **必须**：发布流程可重复（脚本化 / 文档化），不依赖个人记忆

## 2. Tag 规范

- **必须**：发布 tag 命名统一格式，如 `v<major>.<minor>.<patch>`（带 `v` 前缀），全仓库一致，不与业务分支命名混用
- **必须**：tag 打在已合入主干（或对应发布分支）的提交上，禁止在未合并的临时分支上打发布 tag
- **应该**：预发布版本使用 SemVer 预发布标识（如 `v1.2.0-rc.1`），正式发布前完整走完预发布验证
- **禁止**：已发布的 tag 事后移动指向（改变已发布 tag 对应的提交）——发布 tag 一旦推送即视为不可变
