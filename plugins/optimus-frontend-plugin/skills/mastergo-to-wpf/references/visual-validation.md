# 可选视觉验证

视觉验证不属于 CLI 成功条件。没有截图、运行条件或用户授权时，正常交付转换结果并在报告保留 `visual validation was not executed`。

启用条件：用户提供完整设计截图（局部图需注明页面区域）、目标 WPF 项目能运行、用户明确选择比较。流程：

1. 轻量审阅：元素完整性、布局层次、关键间距、颜色、字体、圆角、阴影、滚动边界。
2. 运行目标页面并用 `optimus-qa-ui-consistency-check` 或等效已配置检查生成模块级差异报告。
3. 只有用户明确选择自动修正时，最多三轮；每轮仅处理严重项和有限中等项，并允许用户中止。
4. 输出当前 XAML、差异和人工建议；反馈写入项目 `.mastergo-dsl/feedback/{page-name}/`，包含输入版本、差异和修正记录。

不得将某个视觉阈值视为发布承诺，不得自动修改插件的 `references/`、版本或规则文件。
