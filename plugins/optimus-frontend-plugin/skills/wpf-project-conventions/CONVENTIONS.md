# WPF 项目工程约定（wpf-project-conventions）

本文件是 `mastergo-to-wpf-components` 与 `mastergo-to-wpf-page` 两个 skill 的共享事实来源。
**首次使用前必须由项目负责人填写并提交**；文件缺失或关键项为空时，两个 skill 在 Step 1 拒绝生成。

## 1. MVVM 框架

- 框架：<Prism / CommunityToolkit.Mvvm / 原生 MVVM / 其他>
- ViewModel 基类：<如 BindableBase / ObservableObject / 无>
- 命令实现：<如 DelegateCommand / RelayCommand / 无>
- 视图定位器：<是否启用，如 prism:ViewModelLocator>

## 2. 解决方案与编译

- 解决方案路径：<相对仓库根，如 src/App.sln>
- 编译命令：`dotnet build <解决方案路径>`（执行目录：仓库根）
- 目标框架：<如 net8.0-windows>

## 3. 目录结构

- 页面目录：<如 src/Views/>
- ViewModel 目录：<如 src/ViewModels/>
- 主题资源目录：<如 src/Themes/>
- 自定义控件目录：<如 src/Controls/>
- DataTemplate 目录：<如 src/Themes/DataTemplates.xaml>

## 4. 资源字典合并清单

列出项目 `App.xaml` 实际合并的资源字典（如 `Themes/Colors.xaml`、`Themes/Styles.xaml`），
新增生成文件必须登记进此清单，否则编译验证会失败。

## 5. 命名规范

- 资源 key：<如 PascalCase，禁止空格与 `/`>
- 页面命名：<如 {Name}Page.xaml + {Name}ViewModel.cs>
- 组件命名：<优先取自设计稿组件名，不做二次翻译>

## 6. 生成文件落盘规则

- 生成文件一律写入 `## 3` 声明的目录，命名固定为 `*.generated.xaml`（如 `Colors.generated.xaml`）
- 手工接管文件与生成文件分离，生成文件头部必须含 `<!-- generated by optimus-frontend-plugin:mastergo-to-wpf-components; manual edits will be overwritten -->`
