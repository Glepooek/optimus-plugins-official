# 示例：Prism 项目填写样例

## 1. MVVM 框架

- 框架：Prism
- ViewModel 基类：BindableBase
- 命令实现：DelegateCommand
- 视图定位器：启用（prism:ViewModelLocator.AutoWireViewModel="True"）

## 2. 解决方案与编译

- 解决方案路径：src/Optimus.Desktop.sln
- 编译命令：dotnet build src/Optimus.Desktop.sln
- 目标框架：net8.0-windows

## 3. 目录结构

- 页面目录：src/Views/
- ViewModel 目录：src/ViewModels/
- 主题资源目录：src/Themes/
- 自定义控件目录：src/Controls/
- DataTemplate 目录：src/Themes/DataTemplates.xaml

## 4. 资源字典合并清单

- src/Themes/Colors.xaml
- src/Themes/Styles.xaml
- src/Themes/DataTemplates.xaml

## 5. 命名规范

- 资源 key：PascalCase，如 ButtonPrimary、CardTemplate
- 页面命名：LoginPage.xaml + LoginPageViewModel.cs
- 组件命名：直接使用设计稿组件名，如 ActionButton.Primary

## 6. 生成文件落盘规则

- 生成文件写入 src/Themes/，命名 `*.generated.xaml`
- 头部包含 `<!-- generated by optimus-frontend-plugin:mastergo-to-wpf-components; manual edits will be overwritten -->`
