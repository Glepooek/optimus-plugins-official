## [2.0.1] - 2026-09-17

### Fixed
- `.desktop` 字段确认、同名文件覆盖确认、图形安装验收结果确认三处用户确认关口补上显性 🔴 CHECKPOINT 标记，此前仅靠"必须"等文字措辞，darwin-skill 评分中被判不合格。

## [2.0.0] - 2026-09-17

### Changed
- Skill 范围收窄为纯打包与安装验收：输入改为已发布好的产物目录，不再执行 dotnet publish。

### Removed
- 移除 Parcel 自动化打包路线及其许可证/环境选路逻辑。
- 移除对外发布确认（CHECKPOINT）与发布策略选择步骤。

### Added
- 新增 skill 自带的非交互式 `scripts/build-deb.sh` 打包脚本，Step 3 调用它执行打包，不在用户项目中生成或复用脚本。
- 新增图形界面安装验收步骤，与命令行安装验收并列。
- `.desktop` 文件由本 skill 按模板生成到用户指定的目标路径（用户只需提供路径，不要求预先存在该文件），落盘前需用户确认字段内容。

## [1.0.0] - 2026-09-16

### Added
- 新增 Avalonia Debian/Ubuntu 发布工作流，覆盖 Parcel 自动化与官方 `dpkg-deb` 手动打包路线。
- 加入 Linux publish、Debian 控制文件/启动器/桌面入口、依赖、静态检查、干净安装、启动、卸载和升级验收要求。
- 加入公开发布前的人工确认与许可证、密钥、架构、依赖的安全护栏。
