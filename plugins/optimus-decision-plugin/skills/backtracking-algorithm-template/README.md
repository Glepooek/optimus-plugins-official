# backtracking-algorithm-template

> 版本：1.1.0 | 分类：decision

用户面对搜索/约束满足类问题，纠结"该怎么设计回溯框架"时，给出基于《Hello 算法》的状态/选择/剪枝/解判定四要素与"尝试-剪枝-回退"通用模板。

## 触发词 / 内部触发条件

这个问题怎么用回溯解、怎么设计剪枝逻辑、回溯效率太低怎么优化、backtracking template for this problem、how to design pruning logic、回溯出现重复解漏解

## 产出物数据流

用户的搜索/约束满足问题描述（状态/选择/约束） → backtracking-algorithm-template → 结构化框架设计建议
（四要素定义 + 剪枝规则 + 规模评估） → 人工接手，写入实际代码
