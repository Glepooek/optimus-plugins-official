# divide-and-conquer-problem-check

> 版本：1.1.0 | 分类：decision

用户面对可能拆解为子问题的问题，纠结"能不能用分治解"时，给出基于《Hello 算法》的可分解/子问题独立/可合并三条件自检法。

## 触发词 / 内部触发条件

这个问题能用分治解吗、子问题需要合并吗、分治和动态规划该怎么区分、can I use divide and conquer here、is this problem suitable for D&C、子问题是不是独立的

## 产出物数据流

（三条件核对结论 + 替代方案（若不满足）） → 人工接手，决定是否采用分治实现
