# data-structure-selection

> 版本：1.1.1 | 分类：decision

用户在写代码时纠结"这个场景该用什么数据结构"时，给出基于《Hello 算法》的空间换时间权衡框架和选型建议。

## 触发词 / 内部触发条件

用数组还是链表、要不要用哈希表、这个场景该用什么数据结构、array or linked list、should I use a hash map、邻接矩阵还是邻接表、查询变慢了是不是哈希表设计有问题

## 产出物数据流

用户的场景描述（数据规模/读写模式/约束） → data-structure-selection → 结构化选型建议
（结构选择 + 复杂度依据 + 条件性说明） → 人工接手，写入实际代码
