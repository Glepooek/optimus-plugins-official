# Changelog

## [1.2.0] - 2026-08-13

### Added
- 新增 Step 0"需求预告"：处理请求第一步对比 skill 所需信息与用户已提供信息，一次性列出缺失项统一询问，避免逐 Step 反应式追问；用户已提供的信息不重复询问，信息齐全则跳过本步骤。依赖检查（ffmpeg 是否安装）不参与本环节比对——依赖状态非用户可主动提供的信息，不作为缺失项询问用户，也不影响是否跳过本步骤的判断，仍由 Step 1 实际检测

### Fixed
- README"Skill 依赖关系图"补充遗漏的调用依赖：Step4 执行前校验会主动调用 media-analyze 的 ffprobe 命令查询原始分辨率，此前误写为"无上下游依赖，独立使用"

## [1.1.0] - 2026-08-13

### Added
- 新增 Step 2"校验输入文件"（输入参数检查）：输入路径不存在时报错终止
- Step 3"确认输出路径"增加输出目录可写校验（输出参数检查）：目录不存在或不可写时报错终止，输出文件本身此刻不存在不视为失败
- Step 1 环境检测明确失败时的报错终止行为
- "不要做什么"新增 3 条对应依赖/输入/输出硬约束检查的反例

### Changed
- 遵循 `.claude/rules/skill-authoring.md` 新增的"执行前置校验"规范：依赖检查（Step1）、输入参数检查（Step2）、输出参数检查（Step3）为硬约束，检查失败一律终止；运行条件检查（原 Step3，现 Step4）维持"可协商风险"分类，检查失败走 CHECKPOINT 确认而非终止
- Step 编号整体后移：原 Step2（输出路径）→ Step3，原 Step3（执行前校验）→ Step4，原 Step4（执行转换）→ Step5

## [1.0.1] - 2026-08-13

### Added
- Step 2/Step 3 增加显性 🔴 CHECKPOINT 标记（输出路径确认、放大画质损失与宽高比拉伸变形的执行前校验）
- 新增"不要做什么"章节，列出 5 条反例，含跨 skill 边界说明（压缩诉求应另调 media-compress）
- "失败处理"新增本 skill 特有的 ffmpeg 报错场景（目标宽高非偶数）

### Changed
- 原 Step 3"执行转换"拆分为 Step 3"执行前校验" + Step 4"执行转换"，放大/宽高比校验独立成步，与失败处理表分离
- Step 3 校验顺序改为"先无条件查询原始分辨率，再判断放大/比例"，修正此前"先判断放大与否再查询"的因果倒置问题

## [1.0.0] - 2026-08-12

### Added
- 新增 media-resize skill：基于 ffmpeg `-vf scale` 实现视频分辨率转换，音频流透传不重新编码
