# Changelog

## [1.0.2] - 2026-08-15

### Added
- Step 0 补充自然语言批量/合集意图的主动识别与终止分支；Step 2 补充纯播放列表/合集 URL（无具体视频 ID）的识别与终止分支，避免依赖 `--no-playlist` 对此类链接被动兜底失效（yt-dlp 对无视频 ID 的纯播放列表 URL 会忽略 `--no-playlist` 直接下载整个列表）

### Fixed
- 功能概述补全"不用于规避版权保护措施"这一使用范围声明，与设计文档要求的三点声明（仅限用户本人有权访问、遵守平台服务条款、不用于规避版权保护措施）对齐

## [1.0.1] - 2026-08-15

### Fixed
- Step 4/Step 5 的 yt-dlp 命令补充 `--no-playlist` 参数，从命令层面强制落实"不支持播放列表批量下载"边界，避免用户提供播放列表内单条视频链接时被 yt-dlp 默认行为下载整个播放列表

## [1.0.0] - 2026-08-15

### Added
- 新增 media-download skill：基于 yt-dlp 下载单个在线视频/音频链接，下载前查询可用格式供用户选择，通过 ffmpeg 合并分离的音视频流；不支持播放列表批量下载与需要登录凭据的内容，不接入现有组合请求编排链条
