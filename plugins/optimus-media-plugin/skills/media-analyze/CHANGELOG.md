# Changelog

## [1.1.2] - 2026-08-16

### Fixed
- Step 4 补充"流存在但字段缺失"（如 PCM 等无损编码音频流通常无 `bit_rate`）与"无该流"的区分：前者展示为"未知"，不展示 `undefined`/`null`，也不误判为整体解析失败（darwin-skill 评估 dim3/dim8 优化）
- "不要做什么"章节同步新增对应反例条目

## [1.1.1] - 2026-08-14

### Changed
- Step 0/1/2 需求预告与终止分支新增 🔴 CHECKPOINT / ⛔ STOP 显性视觉标记，强化"必须停下确认"的可执行性（darwin-skill 评估 dim4 优化）
- Step 3 补充 ffprobe 返回非零退出码或 `streams` 为空时的显式终止分支，覆盖"文件存在但无法解析"（已损坏/格式不受支持）的失败中间态
- "不要做什么"章节同步新增对应反例条目

## [1.1.0] - 2026-08-13

### Added
- 新增 Step 0"需求预告"：处理请求第一步对比 skill 所需信息与用户已提供信息，一次性列出缺失项统一询问；输入路径缺失则询问；ffprobe 依赖不参与本环节比对，由 Step 1 实际检测
- 新增 Step"校验输入文件"（输入参数检查）：输入路径不存在时报错终止
- Step 1 环境检测明确失败时的报错终止行为
- 新增"不要做什么"章节，列出 3 条反例

### Changed
- Step 编号整体调整：新增 Step0/Step2，原 Step2（执行分析）→ Step3，原 Step3（整理输出）→ Step4
- README"产出物数据流"与"Skill 依赖关系图"同步更新：与 media-trim 之间从"被动提示"改为"media-trim 主动调用本 skill"，构成实际调用依赖

## [1.0.1] - 2026-08-13

### Added
- 失败处理章节新增说明：本 skill 为只读查询，可在组合请求中随时先行调用确认原始参数，不参与顺序编排

## [1.0.0] - 2026-08-12
